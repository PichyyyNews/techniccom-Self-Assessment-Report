# มาตรฐานและตัวบ่งชี้การประกันคุณภาพการศึกษา (อาชีวศึกษา)
### Vocational Education Quality Assurance Standards & Indicators Reference

เอกสารฉบับนี้รวบรวมโครงสร้างมาตรฐานการประเมินคุณภาพการศึกษาของสถานศึกษาอาชีวศึกษา สำหรับนำมาใช้เป็นฐานข้อมูลตัวบ่งชี้ในระบบ TechSAR

---

## 1. มาตรฐานที่ 1: คุณลักษณะของผู้สำเร็จการศึกษาอาชีวศึกษาที่พึงประสงค์
- **1.1 ด้านความรู้**: ผลสัมฤทธิ์ทางการเรียน ผลการทดสอบทางการศึกษาระดับชาติด้านอาชีวศึกษา (V-NET)
- **1.2 ด้านทักษะและการประยุกต์ใช้**: ทักษะวิชาชีพ ทักษะการปฏิบัติงาน สมรรถนะตามมาตรฐานอาชีพ
- **1.3 ด้านคุณธรรม จริยธรรม และค่านิยมที่พึงประสงค์**: ความมีวินัย ความรับผิดชอบ จิตอาสา
- **1.4 ด้านนวัตกรรม สิ่งประดิษฐ์ งานสร้างสรรค์ หรืองานวิจัย**: การประกวดสิ่งประดิษฐ์และโครงงานวิชาชีพ

## 2. มาตรฐานที่ 2: การจัดการอาชีวศึกษา
- **2.1 ด้านหลักสูตรอาชีวศึกษา**: การพัฒนาและปรับปรุงหลักสูตรให้สอดคล้องกับความต้องการของตลาดแรงงาน
- **2.2 ด้านการจัดการเรียนรู้**: แผนการจัดการเรียนรู้มุ่งเน้นสมรรถนะและการบูรณาการ Active Learning
- **2.3 ด้านการจัดการศึกษาระบบทวิภาคี**: ความร่วมมือกับสถานประกอบการ การนิเทศนักศึกษาฝึกงาน
- **2.4 ด้านครูและบุคลากรทางการศึกษา**: คุณวุฒิ การพัฒนาตนเอง และการจัดการเรียนการสอนของครู
- **2.5 ด้านอาคารสถานที่ ห้องปฏิบัติการ และสื่อการเรียนรู้**: ความพร้อมของเครื่องมือ อุปกรณ์ ครุภัณฑ์

## 3. มาตรฐานที่ 3: การสร้างสังคมแห่งการเรียนรู้
- **3.1 ด้านความร่วมมือในการสร้างสังคมแห่งการเรียนรู้**: การจัดกิจกรรมถ่ายทอดองค์ความรู้แก่ชุมชน
- **3.2 ด้านการวิจัย นวัตกรรม และสิ่งประดิษฐ์**: การเผยแพร่องค์ความรู้และผลงานวิชาการของแผนกวิชา

## 4. มาตรฐานที่ 4: การบริการวิชาชีพและจิตอาสา
- **4.1 ด้านการบริการวิชาการและวิชาชีพ**: โครงการศูนย์ซ่อมสร้างเพื่อชุมชน (Fix It Center) การอบรมวิชาชีพระยะสั้น
- **4.2 ด้านจิตอาสาและทำนุบำรุงศิลปวัฒนธรรม**: การจัดกิจกรรมช่วยเหลือสังคมและการอนุรักษ์วัฒนธรรม

## 5. มาตรฐานที่ 5: การบริหารจัดการและภาวะผู้นำ
- **5.1 ด้านการบริหารจัดการแผนกวิชา**: การจัดทำแผนปฏิบัติการประจำปี (Action Plan) การบริหารงบประมาณ
- **5.2 ด้านการประกันคุณภาพภายใน**: กระบวนการ PDCA และการจัดทำรายงาน SAR ประจำปีการศึกษา
